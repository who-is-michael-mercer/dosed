# ADR 0002: Complete emergency shell in Phase 1

Status: accepted — 2026-09-04

The plan placed the full emergency pathway in Phase 2, while the later locked brief
requires the offline bands and unknown/multiple-substance behavior in Phase 1. We
follow the newer product requirement. The alternative—an interim placeholder—would
fail the explicit acceptance path and create a dangerous dead end. A configurable
112 dialer fallback is intentionally limited pending launch-market decisions; a
worldwide directory is out of scope. Clinical approval remains a release gate.
